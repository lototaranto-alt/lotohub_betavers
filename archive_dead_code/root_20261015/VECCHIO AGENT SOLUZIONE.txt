#### B. La rimozione da `app.json` / `eas.json` rompe il download delle librerie native?
* **Assolutamente NO, anzi: tenerlo in `app.json` è sconsigliato.**
  * In Expo/React Native moderno (`@rnmapbox/maps`), il token segreto di download **non deve mai stare in chiaro nei file di configurazione versionati**.
  * **Per le build locali Gradle (APK di test)**: Gradle legge il token dalla variabile d'ambiente di sistema `MAPBOX_DOWNLOADS_TOKEN` o dal file locale `~/.gradle/gradle.properties` sul PC di sviluppo.

Questo invalida tutti i tag storici, rende complessa qualsiasi futura operazione di comparazione e richiede un `git push --force`.
* **Le due alternative più sicure:**

Da quella pagina web puoi marcare il segreto come *"Used in tests / False positive / Revoked"* oppure autorizzare l'eccezione ("Allow secret").
